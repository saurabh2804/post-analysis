# post-analysis
Analysing Gromacs repository  
The repository carries scripts to analyse the MD simulation trajectories obtained from gromacs  
Chanage the file names before you use the script. This one analyses the files generated with CHARMM-GUI (after running the simulation)
If you use this script, please cite this paper (It was created for this paper):    

Mishra J, Tripathi AK, Sharma S, Mayank, Sahu A, Khan AA, et al. Structural and dynamic implications of the R136H mutation in DNA GyrB: insights into antimicrobial resistance and novobiocin efficacy. New J Chem. 2025 Sept 15;49(36):15911–22.
